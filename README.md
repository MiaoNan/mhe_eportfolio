# Michael He — Portfolio

Personal portfolio showcasing my applied AI, machine learning, and software development experience. Built with Astro, Tailwind CSS, and TypeScript.

**Website:** https://miaonan.github.io/mhe_eportfolio/

## Development

```bash
npm install
npm run dev
```

Edit `src/config.ts` to update personal information, skills, projects, experience, education, and languages.

```bash
npm run build     # Build to dist/
npm run preview   # Preview the production build
```

## Deployment

In repository **Settings → Pages**, set **Source** to **GitHub Actions**. Push to `main` or `master` to run the **Deploy Portfolio** workflow.

The GitHub repository is `MiaoNan/mhe_eportfolio`. If your local remote still uses the old name, update it:

```bash
git remote set-url origin https://github.com/MiaoNan/mhe_eportfolio.git
```
